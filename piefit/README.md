# piefit

Interface do PieFit. A visão geral do projeto, a API e como subir os dois juntos estão no [README da raiz](../README.md).

```bash
npm install
npm run dev
```

O app abre em [http://localhost:3000](http://localhost:3000) e fala com a API em `NEXT_PUBLIC_API_URL` (padrão `http://localhost:3001`).
